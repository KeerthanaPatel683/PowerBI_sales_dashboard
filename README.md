Power BI Sales Dashboard

Overview
This project presents an interactive sales dashboard built using Power BI to analyze revenue trends and product performance.

Features
- Revenue trend analysis over time
- Product performance comparison
- Quantity-based demand insights
- Interactive filtering using slicers

Tools Used
- Power BI
- Excel

Key Insights
- Laptop generates highest revenue
- Phone shows consistent performance
- Sales trends vary over time
